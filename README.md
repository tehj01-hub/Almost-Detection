## Finding files and debugging

Start with the [project file and debugging guide](docs/PROJECT_MAP.md). It lists
the folders, maps features and common bugs to their files, documents moved files,
and provides the current server and test commands.

Shared PHP code is in `app/`, browser scripts in `assets/js/`, checks in `tests/`,
training material in `training/`, SQL in `database/`, and setup notes in
`docs/setup/`. Public PHP pages and Python server launch files remain at the root.
